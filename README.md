# Trabalho avaliativo G2 da cadeira de IOT

Foi desenvolvido um sistema que reconhece se a pessoa está parada, caminhando ou pulando.

Foi utilizado um acelerômetro para a captura dos dados para treinamento. O treinamento foi realizado na plataforma Edge Impulse.

Foram utilizados leds para ser o atuador.

Foi além disso, postado a classe atual do acelerômetro no MQTT.
